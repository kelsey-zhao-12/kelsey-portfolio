# Kelsey Portfolio

First local iteration of a personal website built with React, TypeScript, and Vite.

## What is included

- A concise, light-themed one-page site
- Resume-derived content in a typed data file
- Separate sections for experience, projects, skills, and education
- A structure that is easy to expand into case studies or multi-page navigation later

## Local development

This machine does not currently have `node` installed, so the app could not be started yet from this environment.

Once Node.js is installed:

```bash
cd /Users/swzhao/Documents/Playground/kelsey-portfolio
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.
